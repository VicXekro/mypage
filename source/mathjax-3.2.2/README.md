# MathJax 3.2.2

Vendored `es5/tex-svg-full.js` from the official `mathjax` npm package:
https://cdn.jsdelivr.net/npm/mathjax@3.2.2/es5/tex-svg-full.js

License: Apache-2.0; see `LICENSE` in this directory.

The full TeX/SVG component includes TeX extensions and SVG font data so normal
abstract typesetting works locally without a CDN. The site's configuration lives
in `../js/abstracts.js`. Keep that script before this bundle in the HTML.

MathJax API documentation:
https://docs.mathjax.org/en/v3.2/web/typeset.html
